# 네모로직 도안 만들기

도구: `tools/nono-import.py`(PNG·TXT 검증), `tools/nono-from-icons.py`(아이콘 변환).
작업 폴더 `_incoming/` 는 `.git/info/exclude` 에 등록돼 커밋하지 않는다.

## 채택 기준
줄 추론만으로 풀리는 `ok` 만 채택한다. `guess-unique`·`ambiguous`·`bad-shape` 는 제외하고 이유를 보고한다.
(페이지 생성기가 논리로 풀리는 문제만 쓰므로 `guess-unique` 도 기본은 제외)

## 미리보기 형식
후보를 보여줄 때는 **⬛(칠함) ⬜(빈칸) 이모지로 코드블록 안에** 넣는다.
`■·` 는 가로가 좁아 휴대폰에서 그림이 세로로 찌그러져 보인다. 큰 판도 줄이지 말고 그대로 보여준다.

## 공통 마무리
1. `nono-art.js` 기존 도안과 격자 중복(좌우 반전 포함)·이름 중복을 확인한다.
2. 크기별 위치에 `{ n:'닻', e:'⚓', s:9, r:[…] }` 형태로 추가한다.
3. 추가한 목록을 짧게 보고한다.
4. "올려줘" 면 CLAUDE.md D절로 `nono-art.js` 만 커밋·푸시.

현재 판 크기는 **5×5~25×25** 까지만 쓴다(2026-09-29 기준). 26 이상은 도안도 게임 코드도 제거됐다.

## 1. 큰 판 15~25 — 아이콘 변환
사용자 표현 예: "20x20 후보 보여줘", "25x25 동물로 후보"

1. `python tools/nono-from-icons.py make <N> --count 12`
   주제 지정은 `--theme 동물/자연/음식/탈것/건물/물건/옷/놀이/사람`
2. 출력된 번호별 미리보기를 위 형식으로 보여준다.
3. 사용자가 번호를 고르면 `python tools/nono-from-icons.py pick <N> 2,5,7` → 나온 항목을 공통 마무리로 추가.
4. 후보가 부족하면 `--bold`(윤곽선 스타일)나 다른 `--theme` 로 다시 만든다.

## 2. 중간 판 10~14 — 직접 설계
사용자 표현 예: "12x12 도안 5개 만들어줘"

1. 주제를 정해 격자를 직접 설계해 `_incoming/nono/draft-<N>.txt` 에 쓴다.
   형식: `@ 이름 이모지` 줄 다음에 `#`/`.` 격자 N줄, 도안 사이는 빈 줄. 요청 개수보다 2~3개 더 만든다.
2. `python tools/nono-import.py _incoming/nono/draft-<N>.txt` 로 검증.
3. `ok` 가 아닌 것은 고쳐서 다시 검증(최대 3회). 형태가 알아보기 어려우면 과감히 버린다.
4. 통과분 미리보기를 보여주고 사용자가 고른 것만 추가.

## 3. GPT 가 만든 PNG
사용자 표현 예: "도안 가져와줘"

사용자가 흑백 PNG(한 장에 한 도안, 파일명 `9x9_02_anchor.png`)를 `_incoming/nono/` 에 넣어 둔다.

1. `python tools/nono-import.py _incoming/nono --json _incoming/nono/result.json`
2. 파일명의 영어 이름을 한국어로 바꾸고 이모지를 붙여 공통 마무리.
3. 푸시 후 처리한 PNG 는 `_incoming/nono/done/` 으로 옮긴다.
