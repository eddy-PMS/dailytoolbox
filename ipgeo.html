IP 주소 위치 조회

IP 주소를 넣으면 어디 IP인지 알려드려요

국가·지역·도시, 통신사, 시간대를 조회해요. 위치는 도시 단위 근사치이며, 사람의 실제 위치를 찾는 용도로는 쓸 수 없어요.

IP 주소를 입력하고 조회를 눌러주세요

알아두세요

· IP 위치는 통신사가 IP를 배정한 지역의 추정치예요. 실제와 수십 km 이상 차이 나는 일이 흔하고, 휴대폰 IP는 통신사 게이트웨이(주로 서울)로 잡힙니다.
· 사설 IP(192.168.x.x, 10.x.x.x 등)는 인터넷 상 위치가 없어 조회되지 않아요.
· 무료 조회 데이터를 사용하므로 하루 조회량이 많으면 잠시 제한될 수 있어요. 같은 IP는 30일간 캐시되어 빠르게 응답합니다.

IP 위치 조회는 어떻게 작동하나요

IP 위치 조회는 "이 IP 대역을 어느 통신사가 어느 지역에 등록했는가"를 모아둔 데이터베이스를 찾아보는 방식이에요. 그래서 국가는 거의 정확하지만 도시는 근사치이고, 정확한 주소는 알 수 없어요. 국내 통신사 IP는 서울로 표시되는 경우가 많고, 휴대폰 IP는 실제 위치와 무관하게 통신사 게이트웨이 위치로 잡힙니다.

이 도구는 IP를 넣으면 국가·지역·도시, 통신사(ISP), AS 번호, 시간대, 위도·경도를 보여줘요. 스팸 메일 발신지 확인, 서버 접속 로그 분석, 게임 서버 위치 확인, 의심스러운 로그인 알림의 출처 확인에 쓰세요.

사용 방법

  1. IP 주소(IPv4 또는 IPv6)를 입력하고 "조회"를 누르세요.
  2. "내 IP 넣기"로 현재 접속 IP를 바로 조회할 수 있어요.
  3. 위치 옆 "지도에서 보기"로 대략적인 지점을 지도에서 확인할 수 있어요.

자주 묻는 질문

IP로 누가 사는지 알 수 있나요?

아니요. IP는 통신사가 회선에 배정한 번호일 뿐이고, 가입자 정보는 통신사만 알며 법원 영장 없이는 공개되지 않아요. 이 도구는 지역과 통신사 수준까지만 보여줍니다.

조회 결과가 다른 사이트와 다른데요?

사이트마다 다른 IP 데이터베이스를 쓰기 때문에 도시가 다르게 나올 수 있어요. 국가·통신사는 대체로 일치합니다.

하루 조회 횟수 제한이 있나요?

무료 조회 데이터를 사용하기 때문에 한 사람이 짧은 시간에 아주 많이 조회하면 잠시 제한될 수 있어요. 일반적인 사용에는 문제없습니다.
