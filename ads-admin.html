광고 관리

전 페이지의 광고 자리 6곳을 여기서 켜고 끄고, 애드센스 단위·이미지 배너·직접 코드(HTML)를 배정해요. 자리마다 페이지별로 다른 배너도 넣을 수 있어요. 저장하면 5분 안에 전 페이지에 반영돼요. 페이지를 다시 배포할 필요가 없어요.

관리자 인증

토큰은 이 브라우저에만 저장돼요. Cloudflare 대시보드 → Workers → 이 워커 → Settings → Variables and Secrets 에 ADMIN_TOKEN으로 등록한 값과 같아야 해요.

전체 설정

개인정보처리방침·소개 같은 페이지는 빼두는 게 좋아요. 게임 페이지는 조작 영역 근처에 광고가 없도록 이미 배치돼 있어요.

자리별 설정

이미지 배너: 이미지 파일(PNG·JPG·GIF·WebP, 1MB 이하)을 올리고 누르면 이동할 주소를 넣어요. 화면보다 큰 이미지는 폭에 맞춰 줄어들어요. PC용과 휴대폰용을 따로 올릴 수 있고, 휴대폰용을 비워 두면 PC용이 같이 쓰여요. 페이지별 배너: 고른 페이지에서는 기본 배너 대신 그 배너가 나오고, 여러 묶음에 같은 페이지가 있으면 위쪽 묶음이 이겨요. 특정 페이지에만 배너를 내고 싶으면 자리의 “사용”은 켜 두고 기본 배너의 이미지를 비워 두세요.

애드센스: 콘솔에서 만든 광고 단위의 슬롯 ID(data-ad-slot 숫자)만 넣으면 돼요. 직접 코드: 다른 네트워크 태그나 자체 배너 HTML을 그대로 붙여넣어요(<script>도 실행돼요). 최소 높이는 광고가 늦게 떠도 화면이 밀리지 않게 미리 비워두는 값이에요.
