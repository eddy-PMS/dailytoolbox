아스키 아트란
아스키 아트는 문자만으로 그림이나 글자 모양을 표현하는 방식이에요. 텍스트 모드는 짧은 단어를 5×5 픽셀 블록 문자로 크게 만들어줘서 터미널 배너, 커밋 메시지, 카톡 프로필 문구, README 파일 제목에 쓰기 좋아요. 이미지 모드는 사진의 밝고 어두운 정도를 문자 농도로 바꿔서, 사진을 문자로만 그린 것처럼 표현해요.
이미지 변환은 밝은 부분엔 성긴 문자(공백·점), 어두운 부분엔 빽빽한 문자(@, %, #)를 배치하는 원리예요. 가로 문자 수를 늘리면 더 정교해지지만 브라우저가 그리는 데 시간이 더 걸리고, 복사했을 때 줄이 길어져 다른 곳에 붙여넣기 불편할 수 있어요.


아스키 아트 활용 예
용도추천 설정
깃허브 README 제목텍스트 모드, 6~8글자 이내
카톡 대화방 이름/상태메시지텍스트 모드, 짧은 단어
인스타 프로필 배경 느낌이미지 모드, 흑백, 너비 60~80
재미로 출력해보기 (콘솔 등)이미지 모드, 흑백, 너비 80~120


사용 방법
  1. 텍스트 탭에서 단어(영문·숫자, 최대 12자)를 입력하면 큰 아스키 글자가 만들어져요.
  2. 이미지 탭에서 사진을 올리고 가로 문자 수와 색상 모드를 정하세요.
  3. "복사"로 결과를 가져가 원하는 곳에 붙여넣으세요.






자주 묻는 질문
한글도 큰 글자로 만들 수 있나요?
현재 텍스트 모드는 영문·숫자·일부 기호만 지원해요. 한글은 자모 조합이 복잡해 정확한 블록 폰트를 아직 지원하지 않아요.
이미지가 너무 크면 어떻게 되나요?
가로 문자 수를 기준으로 자동 축소해 처리하니 원본 크기와 상관없이 동작해요. 다만 아주 큰 사진은 변환에 몇 초 걸릴 수 있어요.
컬러로 복사하면 색이 유지되나요?
메모장이나 카톡처럼 일반 텍스트로 복사하면 문자만 복사되고 색은 빠져요. 색을 유지하려면 화면을 캡처하세요.

  
이미지는 브라우저 안에서만 처리되며 서버로 전송되지 않아요. 컬러 모드는 화면에서만 색이 보이고, 일반 텍스트로 복사하면 흑백 문자만 복사돼요.
