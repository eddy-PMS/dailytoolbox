로또 번호 생성기 사용 전에 알아둘 것

로또 6/45는 1부터 45까지의 숫자 중 6개를 맞히는 게임이에요. 1등 확률은 8,145,060분의 1로, 어떤 번호 조합을 고르든 확률은 똑같습니다. "자주 나온 번호"나 "안 나온 번호"를 고른다고 확률이 달라지지 않아요. 이 생성기는 브라우저의 난수로 완전히 무작위 번호를 뽑아드리는 도구예요.

다만 다른 사람과 같은 번호를 피하고 싶다면 무작위 추첨이 유리해요. 생일 숫자(1~31)에 몰린 조합은 당첨 시 여러 명과 나눠 가질 가능성이 높기 때문입니다.

사용 방법

  1. 게임 수(1~10)를 정하세요.
  2. 꼭 넣고 싶은 번호는 "고정 번호"에, 빼고 싶은 번호는 "제외 번호"에 쉼표로 구분해 입력하세요.
  3. "번호 생성"을 누르면 공 색깔과 함께 번호가 나와요. "복사"로 메모장에 옮길 수 있어요.

자주 묻는 질문

자동과 수동 중 뭐가 더 잘 되나요?

확률은 완전히 같아요. 역대 1등 당첨자 중 자동 선택 비율이 높은 건 자동으로 사는 사람이 더 많기 때문입니다.

공 색깔은 무슨 의미인가요?

실제 로또 추첨 공 색깔이에요. 1~10 노랑, 11~20 파랑, 21~30 빨강, 31~40 회색, 41~45 초록입니다.

생성된 번호가 저장되나요?

아니요. 새로고침하면 사라지니 마음에 드는 조합은 "복사"로 보관하세요.

무작위 번호는 당첨 확률을 높이지 않아요(모든 조합의 확률은 같아요). 로또는 재미로, 무리하지 않게.
