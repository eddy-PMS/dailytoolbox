눈이 좋은 게 아니라 집중력이 좋은 겁니다

같은 색 타일 사이에 딱 하나, 아주 살짝 밝기가 다른 타일이 숨어 있어요. 찾아서 누르면 다음 단계로 넘어가고, 단계가 오를수록 타일이 많아지고 색 차이는 줄어들어요. 제한 시간은 60초, 잘못 누르면 2초가 깎여요. 처음엔 누구나 찾지만 20단계를 넘기면 화면을 노려봐야 하고, 30단계쯤 되면 모니터 밝기까지 신경 쓰이기 시작해요.

단계마다 색상(빨강·초록·파랑·보라…)이 무작위로 바뀌고, 다른 타일은 명도만 살짝 달라요. 그래서 색상 구분보다는 미세한 밝기 차이를 알아채는 감각과 화면 전체를 훑는 집중력이 기록을 좌우해요. 시간이 끝나면 도달 단계로 이번 주 랭킹과 전체 랭킹에 등록할 수 있어요.

단계 올리는 요령

  1. 한 칸씩 보지 말고 화면 전체를 흐릿하게 보세요. 다른 칸이 '튀어' 보여요.
  2. 못 찾겠으면 고개를 살짝 뒤로 빼거나 눈을 가늘게 떠보세요.
  3. 찍지 마세요. 틀리면 2초가 사라져요.
  4. 화면 밝기를 중간 이상으로, 주변이 너무 밝지 않은 곳에서 하면 유리해요.

자주 묻는 질문

몇 단계면 잘하는 건가요?

60초 안에 15단계면 보통, 25단계를 넘기면 상위권이에요. 30단계 이후는 색 차이가 아주 작아져서 모니터·조명에 따라 체감이 달라져요.

색약이 있으면 불리한가요?

밝기 차이로 구분하도록 만들어서 색상 자체의 구분 능력보다는 명도 감각을 봐요. 다만 화면 밝기와 주변 조명의 영향을 받으니 같은 환경에서 비교하는 게 좋아요.

잘못 누르면 어떻게 되나요?

남은 시간이 2초 줄어들고 같은 단계를 다시 풀어요. 단계가 내려가지는 않아요.

랭킹은 어떻게 등록하나요?

시간이 끝나면 닉네임을 넣고 등록 버튼을 누르면 돼요. 이번 주 100위 또는 전체 100위 안에 들면 랭킹에 올라가요.

기록은 이 기기의 브라우저에 저장되고, 랭킹 등록 시에만 닉네임과 기록이 서버에 저장돼요.
