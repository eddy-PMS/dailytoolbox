암기 속도는 이렇게 재요

"측정 시작"을 누른 순간부터 10개를 전부 맞힐 때까지의 시간을 재요. 외우는 시간과 테스트 푸는 시간이 모두 들어갑니다. 테스트 사이에 나오는 중간 결과 화면을 보는 동안과, 다른 화면으로 나가 있는 동안은 시계가 멈춰요.

순서는 암기 → 전체 테스트입니다. 전체 테스트를 다 맞히면 거기서 끝나요. 틀린 단어가 있으면 그 단어만 다시 외우고 다시 풀고, 전부 맞히면 10개를 다시 푸는 확인 테스트로 넘어갑니다. 확인 테스트까지 다 맞혀야 시계가 멈춰요.

암기력 테스트 결과 읽는 법

분당 암기 단어 수는 10을 걸린 시간(분)으로 나눈 값이에요. 2분 30초가 걸렸다면 분당 4단어입니다. 단어 하나에는 걸린 시간을 10으로 나눈 값이에요.

1시간 환산(계산값)은 지금 속도가 한 시간 동안 그대로 이어진다고 가정하고 계산한 숫자예요. 실제로 한 시간에 그만큼 외울 수 있다는 뜻은 아닙니다. 오래 하면 집중이 떨어지고, 외운 단어를 다시 보는 시간도 필요하기 때문이에요.

첫 테스트 정답이 10에 가까울수록 한 번에 외웠다는 뜻이고, 다시 외운 횟수가 많을수록 시간이 늘어납니다.

영어 단어 암기, 이 순서로 나와요

단어는 한 번에 하나씩 나와요. 3개씩 묶은 구간을 한 칸씩 밀어 가며 보기 때문에 1·2·3번을 본 다음 2·3·4번, 3·4·5번 순으로 이어집니다. 10개를 한 바퀴 도는 동안 단어마다 3번씩 다시 마주치고, 카드는 모두 32장이에요.

스파르타보카 앱의 윈도우 슬라이딩 암기법과 같은 순서예요. 방식이 더 궁금하다면 윈도우 슬라이딩 암기법 설명을 보세요.

넘기는 방식은 두 가지예요. 자동은 단어 2초, 뜻 2초 뒤에 저절로 넘어가요. 암기 시간이 같아서 테스트를 얼마나 틀리지 않느냐가 결과를 가릅니다. 내 속도는 카드를 누르고 있는 동안 뜻이 보이고, 손을 떼면 다음 단어로 넘어가요.

영단어 외우기, 속도를 올리려면

한 단어를 오래 붙잡고 있기보다 짧게 보고 여러 번 다시 보는 편이 대체로 수월해요. 단어가 나올 때 소리 내어 읽거나 발음을 들으면 눈으로만 볼 때보다 단서가 하나 더 생깁니다. 뜻을 보기 전에 먼저 떠올려 보는 것도 도움이 돼요. "내 속도"에서 카드를 누르기 전에 뜻을 생각해 보세요.

아는 단어를 빨리 맞히는 연습은 영단어 스피드 퀴즈, 지금 어휘 수준을 알아보려면 영어 레벨 테스트를 쓰세요.

자주 묻는 질문

암기 속도는 어떻게 계산하나요?

측정 시작을 누른 때부터 10개를 전부 맞힐 때까지 걸린 시간을 재고, 10을 그 시간(분)으로 나눠 분당 암기 단어 수를 구해요. 외우는 시간과 테스트 시간이 모두 들어가고, 중간 결과 화면을 보는 동안은 빠집니다.

1시간 환산은 실제로 그만큼 외울 수 있다는 뜻인가요?

아니요. 지금 속도가 한 시간 동안 그대로 이어진다고 가정한 계산값이에요. 실제로는 집중이 떨어지고 외운 단어를 다시 보는 시간도 필요해서 이보다 적어집니다.

중학·고교·토익 수준은 어떤 단어인가요?

수준마다 100단어를 담아 두었고, 측정할 때마다 그 가운데 10개가 무작위로 나와요. 이 사이트가 난이도에 맞춰 고른 단어이고, 교육과정이나 시험 주관사의 공식 단어 목록은 아닙니다.

다시 재면 결과가 달라지나요?

네. 재 볼 때마다 단어가 바뀌고, 방식에 익숙해지면 빨라지기도 해요. 아는 단어가 몇 개 섞였는지에 따라서도 달라지니 같은 조건으로 여러 번 재서 비교해 보세요.

외운 단어는 얼마나 오래 기억되나요?

이 도구는 방금 외운 것을 바로 확인한 시간만 재요. 오래 남기려면 한 번에 끝내지 말고 며칠에 걸쳐 간격을 두고 다시 봐야 합니다.
