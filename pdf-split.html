PDF 분할하기

필요한 페이지만 뽑거나, 한 장씩 나누거나

"1-3, 5, 8-10"처럼 페이지 범위를 지정해 새 PDF로 저장하거나, 모든 페이지를 각각 별도 PDF로 나눌 수 있어요. 업로드 없이 브라우저에서 처리해요.

여기에 PDF 파일을 끌어다 놓거나 클릭해서 선택

PDF 분할, 세 가지 방식

① 페이지 범위 추출: "1-3, 5, 8-10"처럼 필요한 페이지만 골라 새 PDF 하나로 저장해요. 긴 보고서에서 제출할 부분만 뽑을 때 써요. ② 페이지별로 나누기: 모든 페이지를 각각 별도 PDF로 저장해요. 급여명세서·성적표처럼 한 파일에 여러 사람 것이 묶인 경우에 유용해요. ③ N쪽씩 나누기: 10쪽씩, 20쪽씩 일정 단위로 쪼개요. 메일 첨부 용량 제한에 맞출 때 좋아요.

모든 처리는 브라우저 안에서 이루어져 파일이 서버로 가지 않아요. 여러 파일이 만들어질 때는 브라우저가 "여러 파일 다운로드를 허용할까요?"라고 물을 수 있는데, 허용하면 순서대로 저장돼요.

페이지 범위 입력 예시

입력결과
1-31, 2, 3쪽
55쪽만
1-3, 7, 10-121, 2, 3, 7, 10, 11, 12쪽을 순서대로
5, 15쪽 다음 1쪽 (입력 순서대로 배치)

사용 방법

  1. PDF를 끌어다 놓거나 선택하면 총 페이지 수가 표시돼요.
  2. 방식(범위 추출 / 페이지별 / N쪽씩)을 고르고 필요한 값을 넣으세요.
  3. "분할하기"를 누르면 새 PDF가 다운로드돼요.

자주 묻는 질문

페이지 순서를 바꿔서 저장할 수 있나요?

네. 범위 추출에서 "3, 1, 2"처럼 입력하면 그 순서대로 배치돼요.

한 번에 여러 범위를 각각 다른 파일로 만들 수는 없나요?

현재는 한 범위가 한 파일이에요. 필요한 만큼 반복해서 추출하세요.

분할한 파일 용량이 원본보다 커요.

폰트·이미지 등 공유 자원이 각 파일에 복사되기 때문이에요. 페이지별 분할 시 흔한 현상이에요.
