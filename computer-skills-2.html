컴활 2급 필기 모의고사

컴퓨터활용능력 2급 필기 출제기준에 맞춰 새로 만든 문제로, 실제 시험처럼 40문항·40분으로 풀고 과목별 점수와 합격 여부를 확인해요.

실전 모드는 과목마다 20문항씩 무작위로 내고 40분이 지나면 자동으로 채점해요. 중간에 그만두면 기록은 남지 않아요.

2027년부터 출제 범위

문제는 대한상공회의소 컴퓨터활용능력 2급 필기 출제기준(2027년 적용)을 바탕으로 새로 만든 연습 문제예요. 실제 시험 문제가 아니며, 시험 정보는 대한상공회의소 자격평가사업단 안내가 기준이에요(확인일 2026-11-12).

컴활 2급 필기 시험 구성과 합격 기준

컴퓨터활용능력은 대한상공회의소가 시행하는 국가기술자격이에요. 2급 필기는 컴퓨터 일반과 스프레드시트 일반 두 과목을 객관식으로 한 번에 봐요.

과목별로 공부할 범위

출제기준에 적힌 세부 항목을 기준으로 정리하면 다음과 같아요. 이 모의고사의 문제도 이 항목마다 고르게 나눠 만들었어요.

1과목 컴퓨터 일반 — Windows 사용법(바로 가기 키, 파일 탐색기, 휴지통, 설정 앱), 컴퓨터 구조(CPU·기억장치·입출력장치, 자료 표현과 진법), 소프트웨어와 PC 관리, 인터넷 프로토콜과 웹, 최신 정보통신기술 용어, 인공지능(AI) 기초, 저작권·개인정보와 보안(악성 코드·해킹 수법).

2과목 스프레드시트 일반 — Excel 화면과 파일·시트 관리, 데이터 입력과 편집, 사용자 지정 서식과 조건부 서식, 셀 참조와 함수(날짜·논리·문자열·수학·통계·찾기 함수), 정렬·필터·유효성 검사, 부분합·피벗 테이블·목표값 찾기 같은 분석 도구, 차트, 페이지 설정과 인쇄, 매크로.

2027년 1월부터 바뀌는 출제기준

대한상공회의소는 2026년 6월 29일 2027~2029년 출제기준을 공지했고, 2027년 1월 1일 시험부터 적용돼요. 2급 필기에서 달라지는 곳은 1과목이에요.

  • 운영체제 기준이 Windows 10에서 Windows 11로 바뀌어요.
  • '인공지능(AI) 기초 활용' 세부 항목(AI의 이해, 기계학습, 활용 사례, 한계와 유의사항)과 'AI 윤리'가 새로 들어가요.
  • '멀티미디어 활용' 세부 항목이 빠지고, 멀티미디어 관련 용어는 최신 정보통신기술 항목 안에 남아요.
  • 2과목 스프레드시트 일반의 범위와 함수 목록, 문항 수·시간·합격 기준은 그대로예요.

이 모의고사는 새 기준으로 만들었어요. 2026년 12월 31일까지는 실전 모드에서 새로 생긴 AI 문항을 빼고 출제하고, 과목별 연습에서는 그 문항에 '2027년부터 출제 범위' 표시를 붙여요. 출처: 대한상공회의소 「2027~2029년 국가기술자격 출제기준 변경 안내」와 자료실의 「2027-2029년 컴퓨터활용능력 출제기준」(확인일 2026-11-12).

필기 합격 기준(과목당 40점·평균 60점)은 1급과 2급이 같아요. 1급은 데이터베이스(Access)가 더해지는 만큼 공부할 양이 많아, 처음이라면 2급부터 시작하는 경우가 많아요.

학점은행제에서 컴활 2급

대한상공회의소 종목 안내에는 학점은행제 학점인정이 1급 14학점, 2급 6학점으로 나와 있어요. 같은 계열 자격을 여러 개 갖고 있을 때 몇 개까지 인정되는지, 내 전공에 넣을 수 있는지는 국가평생교육진흥원 학점은행제 홈페이지의 자격 학점인정 기준에서 확인하세요. 학점은행제로 학위를 준비하는 과정은 학점은행제 편입 정리 글도 참고할 수 있어요.

2주 독학 순서

  1. 1주 차 앞부분: 1과목 용어를 세부 항목별로 훑고, 과목별 연습으로 컴퓨터 일반만 반복해요.
  2. 1주 차 뒷부분: 2과목 함수 결과값 문제를 직접 Excel 에 입력해 보며 셀 참조와 함수를 익혀요.
  3. 2주 차: 실전 모드로 40분 시간을 지켜 풀고, 과목별 점수가 40점 아래인 과목을 먼저 보강해요.
  4. 시험 직전: '틀린 문제만 다시 풀기'로 헷갈린 문항을 정리해요.

함께 준비하는 자격이 있다면 운전면허 필기 모의고사, 실기 대비 입력 속도는 타자 속도 테스트로 연습할 수 있어요.

자주 묻는 질문

시험에 나왔던 문제를 모은 건가요?

아니요. 컴퓨터활용능력 필기는 상시검정으로 치러지고 문제가 공개되지 않아요. 여기 문제는 대한상공회의소가 공개한 출제기준의 범위 안에서 dailyfreetoolbox 가 새로 쓴 연습 문제예요. 실제 시험과 문장·보기가 다르니 범위와 개념을 익히는 데 쓰세요.

시험은 언제 볼 수 있나요?

필기는 상시시험으로 접수해 정해진 시험장·일정에서 봐요. 지역별 시험 날짜와 접수 방법은 대한상공회의소 자격평가사업단 홈페이지(license.korcham.net)의 시험 일정에서 확인하세요.

과락 기준은 어떻게 되나요?

두 과목 모두 100점 만점에 40점 이상이어야 하고, 두 과목 평균이 60점 이상이어야 합격이에요. 평균이 60점을 넘어도 한 과목이 40점 미만이면 불합격이에요.

과목마다 몇 문항씩 나오나요?

대한상공회의소 안내에는 2급 필기가 객관식 40문항·40분이라고만 나와 있어요. 이 모의고사는 과목별 점수를 100점으로 환산하려고 과목마다 20문항씩 나눠 출제하고 채점해요.

2027년에 출제기준이 바뀌면 이 문제로 공부해도 되나요?

이 문제는 2027년 1월부터 적용되는 2027~2029년 출제기준으로 만들었어요. 2026년 12월까지 시험을 본다면 실전 모드가 새로 생긴 인공지능(AI) 문항을 빼고 내므로 그대로 쓰면 되고, 과목별 연습에서는 그 문항에 '2027년부터 출제 범위' 표시가 붙어요.

문제 200개(과목당 100개)는 2027~2029년 출제기준(Windows 11·MS Office 2021) 범위에서 새로 만든 연습 문제예요.
