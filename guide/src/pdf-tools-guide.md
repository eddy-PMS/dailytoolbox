서류를 제출할 때 "PDF 한 파일로 보내 주세요"라는 말을 자주 듣습니다. 스캔한 장수가 여러 개이거나, 사진으로 찍어둔 것을 묶어야 하거나, 반대로 두꺼운 PDF에서 몇 쪽만 뽑아야 할 때가 있어요. 프로그램을 깔지 않고 브라우저에서 해결하는 방법을 정리했습니다.

[[tool:pdf-merge.html|여러 PDF를 순서대로 하나로 묶어요]]

## 무엇을 해야 하는지부터 정하세요

| 상황 | 필요한 작업 |
|---|---|
| 스캔 파일이 여러 개 | PDF 합치기 |
| 두꺼운 문서에서 몇 쪽만 필요 | PDF 분할 (범위 추출) |
| 한 파일에 여러 사람 것이 섞임 | PDF 분할 (쪽별로 나누기) |
| 메일 첨부 용량 초과 | PDF 분할 (N쪽씩) 또는 이미지 압축 |
| 사진·스캔본을 문서로 | 이미지 → PDF |
| PDF를 카톡으로 보내야 함 | PDF → JPG |

## 합치기 — 순서가 전부입니다

여러 파일을 하나로 묶을 때 가장 중요한 건 순서예요. 파일 이름이 `스캔1, 스캔10, 스캔2`처럼 정렬되면 엉뚱한 순서로 묶입니다. 파일명을 `01, 02, 03`처럼 두 자리로 맞춰 두면 이런 일이 없어요.

앞뒤 표지나 서명 페이지를 따로 찍었다면, 합친 뒤에 순서가 맞는지 한 번 넘겨 보세요.

## 나누기 — 세 가지 방식

**범위 추출**은 "1-3, 5, 8-10"처럼 필요한 쪽만 골라 새 PDF 하나로 만듭니다. 긴 보고서에서 제출할 부분만 뽑을 때 써요. 입력한 순서대로 배치되니 "3, 1, 2"처럼 적으면 순서도 바꿀 수 있습니다.

**쪽별로 나누기**는 모든 페이지를 각각 별도 파일로 저장해요. 급여명세서나 성적표처럼 한 파일에 여러 사람 것이 묶인 경우에 유용합니다.

**N쪽씩 나누기**는 10쪽씩, 20쪽씩 일정 단위로 쪼갭니다. 메일 첨부 용량 제한에 맞출 때 좋아요.

## 이미지로 바꾸기

PDF는 미리보기가 안 되는 곳이 많습니다. 메신저로 보내거나 블로그에 넣을 때는 이미지가 편해요. 이때 형식과 화질을 골라야 합니다.

| 선택 | 언제 |
|---|---|
| JPG | 사진이 많은 문서. 용량이 훨씬 작습니다 |
| PNG | 글자·표·도면. 선이 또렷합니다 |
| 화질 보통 | 메신저 전송, 화면으로 보기 |
| 화질 높음 | 대부분의 경우 |
| 화질 최고 | 인쇄, 글자가 작은 문서 |

반대로 사진 여러 장을 문서로 만들어야 하면 이미지 → PDF를 씁니다. 스캐너 없이 휴대폰으로 찍은 서류를 제출용 한 파일로 묶을 때 자주 쓰여요.

:::tip 파일이 밖으로 나가지 않는 것이 왜 중요한가
PDF로 다루는 서류는 대개 민감합니다. 계약서, 급여명세서, 주민등록등본, 의료 기록 같은 것들이죠. 온라인 변환 사이트 상당수는 파일을 **서버에 업로드한 뒤** 처리하고, 일정 시간 뒤 삭제한다고 안내합니다. 삭제를 믿더라도 전송되는 순간 내 손을 떠나는 건 사실이에요. 여기 있는 PDF 도구들은 **브라우저 안에서만** 처리해서 파일이 서버로 전송되지 않습니다. 인터넷을 끊고 페이지를 열어둔 상태에서도 동작하는지 확인해 보면 알 수 있어요. 민감한 서류일수록 어디서 처리되는지 따져 보는 습관이 필요합니다.
:::

## 용량이 문제일 때

메일이나 접수 시스템은 대개 첨부 용량에 제한이 있습니다. PDF가 너무 크면 순서대로 시도해 보세요.

1. **이미지가 원인인 경우가 대부분입니다.** 휴대폰으로 찍은 사진을 그대로 PDF로 묶으면 한 장에 몇 MB씩 됩니다. 이미지를 먼저 압축한 뒤 PDF로 만드세요.
2. **쪽수를 나눕니다.** N쪽씩 나눠 여러 번에 걸쳐 보냅니다.
3. **화질을 낮춥니다.** 화면으로만 볼 문서라면 높은 화질이 필요 없어요.

[[tool:image-compress.html|사진 용량을 줄인 뒤 PDF로 묶으면 크기가 크게 줄어요]]

## 안 되는 경우

**암호가 걸린 PDF**는 읽지 못합니다. 열기 암호를 먼저 푼 뒤에 작업하세요.

**나눈 파일이 원본보다 큰 경우**도 있습니다. 폰트나 이미지처럼 문서 전체가 공유하던 자원이 각 파일에 복사되기 때문이에요. 쪽별 분할에서 흔한 현상이고 정상입니다.

**여러 파일을 한꺼번에 저장할 때** 브라우저가 "여러 파일 다운로드를 허용할까요?"라고 묻습니다. 허용하면 순서대로 저장돼요.

## 자주 묻는 질문

?? 파일이 서버로 올라가나요
아니요. 이 사이트의 PDF 도구들은 브라우저 안에서만 처리하고 파일을 전송하지 않습니다. 계약서나 급여명세서처럼 민감한 서류를 다룰 때 중요한 차이예요.

?? 합칠 때 순서가 뒤죽박죽이에요
파일 이름 정렬 때문입니다. `스캔1, 스캔10, 스캔2` 순으로 읽히는 경우가 많아요. 파일명을 `01, 02, 03`처럼 두 자리로 맞추면 해결됩니다.

?? PDF를 카카오톡으로 보내려면
이미지로 바꾸는 편이 낫습니다. PDF는 미리보기가 안 되는 경우가 많아요. 사진이 많으면 JPG, 글자와 표가 많으면 PNG를 고르세요.

?? 나눴더니 파일이 더 커졌어요
폰트와 이미지처럼 문서 전체가 공유하던 자원이 각 파일에 복사되기 때문입니다. 쪽별로 나눌 때 흔한 현상이고 이상이 아니에요.

?? 암호가 걸린 PDF도 되나요
열기 암호가 걸린 파일은 읽지 못합니다. 암호를 먼저 해제한 뒤에 작업해 주세요.
