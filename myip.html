내 IP 주소 확인

공인 IP 주소, 대략적인 위치(국가·지역·도시), 통신사, 시간대와 브라우저 정보를 보여드려요. 서버에 저장하지 않고 화면에만 표시합니다.

IP 위치는 얼마나 정확한가요?

· IP 위치는 통신사가 IP를 배정한 지역을 추정한 것이라 도시 단위 근사치예요. 실제 위치와 수십 km 이상 차이 나는 경우가 흔합니다.
· 휴대폰 데이터(LTE/5G)는 통신사 게이트웨이 위치로 잡혀 서울로 표시되는 경우가 많아요.
· VPN이나 회사 프록시를 쓰면 그쪽 위치로 표시됩니다. GPS처럼 사람의 위치를 찾는 용도로는 쓸 수 없어요.

내 IP 주소란

IP 주소는 인터넷에서 내 기기(정확히는 내 인터넷 회선)를 식별하는 번호예요. 집에서 공유기를 쓰면 공유기 안쪽 기기들은 192.168.x.x 같은 사설 IP를 쓰고, 인터넷에 나갈 때는 통신사가 배정한 하나의 공인 IP로 나가요. 이 페이지가 보여주는 건 그 공인 IP예요. 원격 접속 설정, 서버 화이트리스트 등록, 게임 서버 개설, IP 차단 문의 때 필요합니다.

IPv4(예: 121.134.xx.xx)와 IPv6(예: 2001:2d8:...)가 함께 쓰이는 시기라 접속 환경에 따라 둘 중 하나가 표시돼요. 통신사 대부분은 아직 IPv4를 주로 쓰지만, 휴대폰 데이터는 IPv6가 우선 잡히는 경우가 많아요.

휴대폰 IP 확인 — 와이파이와 데이터에서 다르게 나오는 이유

같은 휴대폰인데 와이파이를 켰을 때와 끄고 데이터를 쓸 때 IP가 다르게 나와요. 인터넷으로 나가는 길이 다르기 때문이에요.

와이파이모바일 데이터(LTE·5G)
보이는 IP공유기가 물린 회선의 공인 IP통신사 게이트웨이의 IP
위치그 회선이 등록된 지역게이트웨이 위치 — 서울로 나오는 경우가 많음
집에서 PC와 비교하면같은 공유기면 PC와 같은 IPPC와 전혀 다른 IP
IPv6회선에 따라 다름우선 잡히는 경우가 많음

그래서 휴대폰에서 확인한 IP를 집 공유기 설정이나 서버 화이트리스트에 넣으면 안 맞을 수 있어요. 집 회선의 IP가 필요하면 와이파이에 연결한 상태에서 이 페이지를 열어야 합니다.

카페나 회사 와이파이에서는 그곳 회선의 IP가 보여요. 여러 사람이 같은 IP를 함께 쓰기 때문에, 그 IP로는 개인을 가려낼 수 없습니다.

IP로 집 주소·동호수까지 알 수 있나요

없습니다. IP 위치는 GPS가 아니라 통신사가 그 IP 대역을 어느 지역에 등록했는지를 보고 추정한 값이에요. 그래서 도시 단위 근사치이고, 실제 위치와 수십 km 차이가 나는 일이 흔합니다.

위치가 엉뚱하게 나오는 데는 이유가 있어요.

  • 통신사 등록지 기준이라 경기·지방에서도 서울로 나오는 경우가 많아요.
  • 모바일 데이터는 게이트웨이 위치로 잡혀 실제 있는 곳과 무관합니다.
  • VPN·회사 프록시를 쓰면 그쪽 서버 위치로 보여요.

다른 사람의 IP를 넣어 국가·도시를 확인하고 싶다면 IP 주소 조회·추적을 쓰세요. 거기서도 알 수 있는 범위는 똑같습니다.

통신사에 내 IP·접속 기록을 물어볼 수 있나요

"통신사에 물어보면 접속 기록이나 위치를 알 수 있나"를 찾는 분이 많아요. 내 정보를 내가 요구하는 것과 남의 정보를 알아내는 것은 완전히 다릅니다. 아래는 법 조문을 확인해 정리한 내용이에요(확인일 2026-10-04).

내 정보는 요구할 수 있는 길이 있어요.

  • 개인정보 열람 요구 — 개인정보 보호법 제35조는 정보주체가 개인정보처리자에게 자신의 개인정보 열람을 요구할 수 있도록 하고 있어요. 요구를 받으면 10일 안에 열람하게 해야 하고, 법률에 따라 열람이 제한되는 경우 등에는 사유를 알리고 제한하거나 거절할 수 있습니다.
  • 위치정보 이용·제공사실 열람 요구 — 위치정보법 제24조 제3항은 개인위치정보주체가 본인의 위치정보 수집·이용·제공사실 확인자료와, 개인위치정보가 제3자에게 제공된 이유·내용의 열람 또는 고지를 요구할 수 있도록 하고 있어요. 사업자는 정당한 사유 없이 거절할 수 없습니다.

남의 정보는 개인이 알아낼 수 있는 길이 없어요. 누가 언제 접속했는지 같은 통신사실 확인자료는 통신비밀보호법 제13조에 따라 검사나 사법경찰관이 관할 지방법원의 허가를 받아 전기통신사업자에게 요청하는 절차입니다. 같은 조에 개인이 직접 요청할 수 있다는 규정은 없어요.

그래서 "상대방 IP로 그 사람 위치를 알아내 달라"는 요청은 이 도구로도, 통신사에 개인 자격으로 문의해서도 되지 않습니다. 피해를 입었다면 수사기관에 신고하는 것이 절차예요.

본인 확인 방법이나 기록 보관 기간처럼 구체적인 부분은 통신사마다 다르고 이 글에서 확인하지 못했어요. 가입한 통신사 고객센터에 직접 문의하세요.

IP 주소가 어느 통신사·기관 것인지 공식으로 확인하려면

이 페이지에 보이는 통신사 이름은 IP 위치 데이터베이스에서 온 값이에요. 공식 할당 정보를 보려면 한국인터넷진흥원(KISA)이 운영하는 후이즈 검색을 쓰면 됩니다.

whois.kr 에서 IP 주소나 AS 번호를 넣으면 그 주소가 어느 기관에 할당돼 있는지 확인할 수 있어요. 국내 주소뿐 아니라 해외 IP·AS 번호도 조회되고, 도메인 조회도 같은 곳에서 됩니다.

회사·기관이 쓰는 IP 대역을 확인할 때, 또는 이 페이지에 표시된 통신사가 실제 할당 기관과 맞는지 볼 때 쓰면 됩니다. 다만 후이즈도 할당받은 기관까지만 보여 주고 개인 가입자를 알려 주지는 않아요.

IP가 바뀌는 이유 — 유동 IP

공인 IP는 통신사가 주기적으로 바꾸는 유동 IP인 경우가 대부분이에요. 공유기를 껐다 켜거나 며칠 지나면 달라질 수 있습니다.

그래서 서버 화이트리스트 등록이나 원격 접속 설정처럼 IP가 고정돼 있어야 하는 일에 쓸 때는 주의해야 해요. 통신사에 고정 IP 상품을 따로 신청하거나, 바뀔 때마다 다시 등록해야 합니다.

IP를 일부러 바꾸고 싶다면 공유기를 껐다가 10분쯤 뒤에 켜면 바뀌는 경우가 많아요. VPN을 쓰면 VPN 서버의 IP로 보이게 됩니다.

사용 방법

  1. 페이지를 열면 자동으로 공인 IP와 접속 정보가 표시돼요.
  2. "IP 복사"로 클립보드에 복사해 필요한 곳에 붙여넣으세요.
  3. 위치가 실제와 다르면 통신사 등록지 기준 추정치라 그런 것이니 참고만 하세요.

자주 묻는 질문

위치가 실제 사는 곳과 다르게 나와요.

IP 위치는 GPS가 아니라 통신사가 그 IP 대역을 등록한 지역이에요. 경기·지방에서도 서울로 나오는 경우가 흔하고, 휴대폰 데이터는 거의 항상 통신사 게이트웨이 위치로 잡혀요.

내 IP를 다른 사람이 알면 위험한가요?

IP만으로 집 주소나 신원을 알 수는 없어요. 다만 온라인 게임 등에서 IP가 노출되면 DDoS 공격 대상이 될 수 있으니 불특정 다수에게 공개하지 않는 게 좋아요.

IP를 바꾸고 싶으면요?

유동 IP라면 공유기를 껐다가 10분 정도 뒤에 켜면 바뀌는 경우가 많아요. VPN을 쓰면 VPN 서버의 IP로 보이게 됩니다.

휴대폰과 컴퓨터의 IP가 다르게 나와요.

모바일 데이터를 쓰면 통신사 게이트웨이의 IP로 나가기 때문에 집 공유기에 물린 컴퓨터와 전혀 다른 IP가 보여요. 같은 와이파이에 연결하면 둘 다 같은 공인 IP로 보입니다. 집 회선의 IP가 필요하면 와이파이에 연결한 상태에서 확인하세요.

VPN을 켜면 IP가 어떻게 보이나요?

VPN 서버의 IP와 그 서버가 있는 나라·도시로 보여요. 실제 내 IP와 위치는 가려집니다. 회사 프록시를 거칠 때도 마찬가지로 그쪽 위치로 표시돼요.

이 페이지가 내 IP를 저장하나요?

아니요. 접속 정보를 받아 화면에 보여줄 뿐이고 서버에 저장하지 않아요.

위치 정보는 Cloudflare 네트워크가 제공하는 IP 기반 추정치이며, 이 페이지는 조회 결과를 어디에도 저장하지 않습니다.
